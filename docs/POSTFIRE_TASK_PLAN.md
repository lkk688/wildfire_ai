# 方向 2：灾后损毁识别，基线与 SFT 判定规则（预注册）

写定日期：2026-10-21。本文件在任何模型跑出灾后 val 或 test 结果**之前**提交。下文的判定规则一旦提交即固定，不随后续结果调整。

## 1. 任务

- **输入**：起火后 365 天内首次拍摄的 Wayback 航拍（时间核验），以及可选的同一位置灾前影像（用于变化检测）。目标建筑位于图像中心。
- **输出**：
  - 主任务：P(被毁)，二分类，被毁 = Destroyed + Major；
  - 次任务：DINS 的 5 级损毁等级。
- **数据**：`scripts/data/build_postfire_dataset.py` 生成，使用与风险任务相同的事件划分：train 为 2019–2023 年的 train 事件，val 为 val 事件，test 为 2024 年及以后的事件；dev 事件全部排除。每个（事件，损毁等级）最多抽 40 栋。
- **覆盖率**：只有部分建筑有灾后拍摄，覆盖率按事件报告。大火更可能有灾后影像，这是需要报告的选择偏差。

## 2. 对照组

| 组 | 内容 |
|---|---|
| 监督学习基线 | 冻结 DINOv2 或 SigLIP 加逻辑回归（只用灾后图，以及灾前加灾后）；全量微调 DINOv2-small（5 级分类头） |
| 零样本 VLM | Qwen3.8-27B（远程，免费）：test 全量与 val 全量。Sonnet 5.5 和 Haiku 5.5：test 与 val 各取 400 栋固定子集（按事件和类别分层，种子固定）。每个模型都跑"只看灾后"和"灾前加灾后"两种条件 |
| SFT 起点 | 本地 Qwen3.5-4B 的零样本结果（vLLM），在 val 和 test 上各跑一次，作为与 SFT 后对比的同一模型基准 |

## 3. 是否启动 SFT（只看 val，不看 test）

以下两条**同时满足**才启动：

- **G1（差距存在）**：Qwen3.5-4B 零样本的 val AUROC ≤ Sonnet 零样本的 val AUROC − 0.05；
- **G2（任务未饱和）**：微调 DINOv2-small 的 val AUROC < 0.98，即还有可提升空间。

任一条不满足，就不做 SFT，并在结果中记录原因：差距太小说明没有必要；监督基线已经接近饱和，说明 VLM-SFT 的意义只剩可解释性，需要另行论证。

## 4. SFT 方案（固定）

- 模型：Qwen3.5-4B，LoRA（r=16，α=32，作用于全部线性层），最多 3 个 epoch，学习率 1e-4，在 RTX PRO 6000 上训练。
- 数据：`postfire_train`。目标只是一段很短的 JSON：`{"p_destroyed": <0-100>, "damage_level": <DINS 等级>}`。**不写由真值反推的思维链。**
- 模型选择只依据 val AUROC。
- 停止规则：最好一轮的 val AUROC 比零样本高出不到 0.03，就停止，不再调参重试。

## 5. 成功标准（test，只评估一次）

| 编号 | 标准 |
|---|---|
| S1 | SFT 后 Qwen3.5-4B 的 test AUROC ≥ Haiku 零样本的 test AUROC |
| S2 | SFT 后 Qwen3.5-4B 的 test AUROC ≥ 微调 DINOv2-small 的 test AUROC − 0.02 |
| S3（报告） | 5 级损毁的 macro-F1，与微调 DINOv2-small 比较 |
| S4（报告） | 按事件分别报告 AUROC 并给出区间，Eaton 和 Palisades 单独列出 |

S1 和 S2 都满足，才能写"小模型经 SFT 后达到闭源模型和专用模型水平"。只满足 S1，只能写"SFT 缩小了与闭源模型的差距，但没有超过专用模型"。

## 5b. 补充说明（2026-10-21，在看到任何灾后 val 或 test 结果之前写入）

- Qwen3.5-4B 默认开启思考模式。烟测中一张图耗尽 6000 个 token 仍未作答，用时 62 秒。SFT 的目标输出是不含思考的短 JSON，因此**零样本基准改用非思考模式**（`enable_thinking=False`），保证与 SFT 后的模型可比。另在 val 子集（200 栋）上跑一次思考模式（max_tokens=16000），只作为敏感性分析，不参与判定。
- Sonnet 和 Haiku 的 400 栋子集，由 `run_vlm_conditions.py --subset 400` 按（事件，结局）分层、种子 1019 抽取，各模型使用同一批建筑。

## 5c. 补充说明：SFT 的打分方式（2026-10-21，在任何 SFT 运行之前写入）

- 目标文本为 `{"damage_level": "<none|affected|minor|major|destroyed>", "p_destroyed": <整数>}`。
- 打分：只做一次前向，取第一个等级 token 在 5 个选项上的 softmax，P(被毁) = P(major) + P(destroyed)。这样得到的是连续分数，不会出现大量并列。
- 文本中的 p_destroyed 只是按等级映射的固定值（2/8/20/75/98），不参与打分。
- 第 0 轮（未加 LoRA 的基座模型）用同一提示词、同一种打分方式评估，作为 SFT 前后对比的基准。上面"零样本非思考模式"的生成式结果另外报告，用于和其他模型比较。

## 6. 不会做的事

- 不在 test 上选择模型、阈值或提示词。
- 不训练由真值反推的长思维链，也不在这一阶段使用 RL。
- 不把 DINS 的巡查员属性作为输入。

## 7. 结果（2026-10-21，按第 3–5 节的规则判定）

**数据**：train 1,646 / val 303 / test 1,287 栋，其中 1,246 栋同时有灾前和灾后图。在抽样的建筑中，有灾后影像的比例为 42–54%。完整表格见 `output/experiments/postfire/comparison.md`。

**是否启动 SFT（只看 val）**
- G1：Qwen3.5-4B 零样本 0.684，Sonnet 0.918，差距 0.234 ≥ 0.05，通过。若改用 4B 的首 token 打分，基座为 0.832，差距 0.086，仍然通过。
- G2：微调 DINOv2-small 的 val 最好成绩 0.896 < 0.98，通过。

结论：启动 SFT。

**SFT 过程**：val AUROC 第 0 轮 0.832，第 1 轮 0.958，第 2 轮 0.969，第 3 轮 0.967。选第 2 轮。最好成绩比第 0 轮高 0.137，超过 0.03 的门槛，停止规则未触发。

**test（只评估一次）**（区间已与 `output/experiments/postfire/comparison.md` 当前版本同步，2026-10-22；未解析的回答按 p=0.5 计入）

| 编号 | 比较（同一批建筑） | ΔAUROC [95% 事件 CI] | 判定 |
|---|---|---|---|
| S1 | SFT 对比 Haiku 零样本（只看灾后图），400 栋子集 | **+0.095** [+0.045, +0.145] | **通过** |
| S1 | SFT 对比 Haiku 零样本（灾前加灾后图） | +0.039 [+0.007, +0.078] | 通过 |
| – | SFT 对比 Sonnet（只看灾后图）/（灾前加灾后） | +0.065 [+0.016, +0.104] / +0.021 [−0.004, +0.046] | 前者优于 Sonnet，后者持平 |
| S2 | SFT 对比微调 DINOv2-small（预注册的参照），1,246 栋 | **+0.115** [+0.073, +0.155] | **通过** |
| 事后补充 | SFT 对比冻结 DINOv2-base 加 LR（只看灾后 / 灾前加灾后） | **+0.011** [−0.008, +0.029] / +0.002 [−0.020, +0.023] | **持平，没有优势** |
| – | SFT 对比同一基座、同一打分方式（未训练） | +0.130 [+0.081, +0.160] | SFT 本身有效 |
| – | SFT 对比 Qwen3.8-27B 零样本 | +0.191 [+0.113, +0.247] | 4B 经 SFT 后远超 27B 零样本 |
| S3 | 5 级 macro-F1 | SFT 0.362，基座 0.244，微调 DINOv2-small 0.276 | 5 级分类对所有模型都难 |
| S4 | 按事件 AUROC | SFT：Eaton 0.805、Palisades 0.774、Mountain 0.858、Park 1.000 | 城市大火最难；冻结 DINOv2 头在 Eaton 上为 0.804，几乎相同 |

**解读**
1. 按预注册标准，S1 和 S2 都通过，可以写"小模型经 SFT 后超过闭源零样本，也超过预注册的专用模型参照"。但必须同时写明：预注册的 S2 参照（微调 DINOv2-small）本身训练不稳定、成绩偏弱；**一个冻结 DINOv2-base 加逻辑回归就能和 SFT 打平**。只看二分类 AUROC，VLM-SFT 并不比便宜的监督图像模型更好。它的附加价值只能来自输出形式（损毁等级、文字说明、弃答），这些都还没有验证。
2. 打分读出方式影响很大：同一个 4B 基座，让它直接生成数字时 AUROC 为 0.644，读首 token 概率时为 0.762（全量 test）。闭源模型拿不到 logprob，只能用生成数字的方式比较，这一点对它们不利，报告结果时需要说明。
3. 开源和闭源在灾后感知上的差距可以用少量数据（1,646 栋）补上，而且是在没见过的火灾事件上成立。

## 8. 补充预注册：VLM 输出形式的价值，以及 9B 规模复现（2026-10-21，在计算任何下列指标之前写入）

**问题**：二分类 AUROC 上，SFT 与冻结 DINOv2 加逻辑回归打平。VLM 还有没有其他价值？本节检验其中两种可以量化的：5 级损毁分级，以及置信度能否用于弃答。文字解释需要人工评审，不在本节范围内。

**对照组**
- 线性头：冻结 DINOv2-base，PCA 降到 128 维后接逻辑回归，分二分类和 5 分类两种；输入分为只用灾后图，以及灾前、灾后和二者之差。为了和 SFT 一样只把 val 用于选择，**这里线性头只用 train 拟合**。
- SFT：4B（第 2 轮）和 9B（同一套固定方案，按 val 选轮）。
- 零样本模型：Sonnet、Haiku（400 栋子集）和 Qwen3.8-27B（全量）。

**A. 5 级分级**（test 全量 1,246 栋；另在 400 栋子集上报告）
- 主要指标：二次加权 Kappa（QWK）和 macro-F1。
- 次要指标：每级召回率、平均等级误差（MAE，按 0–4 计），以及合并成三组后的准确率（无损 / 轻微 + 轻度 / 严重 + 毁）。
- 判定：SFT 减去线性头（5 分类、灾后图）的差值，若 QWK 和 macro-F1 的 95% 事件 bootstrap 区间下界都 > 0，记为"VLM 在分级上有优势"。

**B. 置信度与弃答**（二分类）
- 阈值 t 在 val 上按最大平衡准确率选定，test 沿用。置信度定义为 |p − t|。
- 主要指标：AURC，即风险—覆盖率曲线下面积，风险为 1 − 准确率，越低越好。
- 业务指标：在准确率 ≥ 95% 和 ≥ 98% 的约束下，最多能自动判定多少比例的建筑（自动判定覆盖率，对应 DINS 巡查分流：容易的自动判，其余交给人）。
- 校准：在 test 上报告 ECE（10 个分箱）和 Brier，分原始概率和用 val 拟合 Platt 缩放后两种。
- 判定：SFT 减去线性头的 AURC 差值，若 95% 区间上界 < 0；或 95% 准确率下的自动判定覆盖率差值，若区间下界 > 0，记为"VLM 在可靠性上有优势"。
- 零样本闭源模型只能用它们生成的 p，在 400 栋子集上一并报告。

**C. 9B 规模复现**：和 4B 用同一脚本、同一超参数，不另作调整。按第 5 节同样的 S1、S2 标准判定，并和 4B 及线性头在同一批建筑上比较。

## 9. 结果：输出形式的价值与 9B 复现（2026-10-21，按第 8 节的规则判定）

完整表格见 `output/experiments/postfire/output_value.md` 和 `comparison.md`。

**C. 9B 规模复现**（同一方案；val 0.785 → 0.959 → 0.974 → 0.974，选第 3 轮；test 只评估一次）

| 比较 | ΔAUROC [95% 事件 CI] |
|---|---|
| 9B SFT 的 test AUROC | **0.903**（4B 为 0.892） |
| 对比 Haiku 零样本（只看灾后图） | +0.100 [+0.050, +0.153]，**S1 通过** |
| 对比 Sonnet 零样本（只看灾后图 / 灾前加灾后） | +0.069 [+0.022, +0.114] / +0.026 [−0.003, +0.055] |
| 对比微调 DINOv2-small | +0.125，**S2 通过** |
| 对比冻结 DINOv2 加 LR（只看灾后图） | **+0.022 [+0.006, +0.035]**，小但显著 |
| 对比冻结 DINOv2 加 LR（灾前加灾后） | +0.013 [−0.001, +0.025]，持平 |
| 对比 4B SFT | +0.011 [−0.003, +0.023]，不显著 |
| 未训练的 9B 基座（同一打分方式） | test 0.709，**比 4B 基座（0.762）还低**；经 SFT 后反而略高 |

**A. 5 级分级**（全量 1,246 栋）

| 模型 | QWK | Macro-F1 | 等级 MAE | 三组准确率 |
|---|---:|---:|---:|---:|
| 线性头（DINOv2，只看灾后图） | 0.615 | 0.322 | 0.835 | 0.629 |
| 4B SFT | 0.670 | 0.362 | 0.676 | 0.689 |
| 9B SFT | 0.692 | 0.367 | 0.675 | 0.671 |

- 4B：QWK +0.054 [−0.056, +0.147]，macro-F1 +0.041 [+0.005, +0.068]，**未达标**（QWK 的区间下界 ≤ 0）。
- 9B：QWK +0.076 [**+0.0001**, +0.158]，macro-F1 +0.045 [+0.005, +0.078]，**勉强达标**。我们检验了 4B 和 9B 两个模型，而预注册时没有规定多重比较校正，所以只能写成"边缘证据"。
- 所有模型在 minor 和 major 两级上的召回率都接近 0：从正上方看几乎分辨不出这两级，而且训练集里 major 只有 21 栋。真正分得开的只有 none / affected 与 destroyed。

**B. 置信度与弃答**
- AURC：4B −0.003 [−0.025, +0.023]，9B +0.013 [−0.008, +0.031]。**两者都没有优势。**
- 准确率 ≥ 95% 时的自动判定覆盖率：全量 test 上所有模型只有 2–10%，这个指标在 bootstrap 中极不稳定，区间宽达 ±0.6。400 栋子集上为 79–86%，因为该子集偏向小型、容易判断的火灾。
- **对 2025 年洛杉矶那类城市大火，"自动判定容易的、其余交给人"的分流方案目前不可行。**
- 校准：SFT 和线性头的原始 ECE 约为 0.03–0.05；Haiku 原始 ECE 为 0.13，经 Platt 缩放后降到 0.03–0.05。

**结论（VLM 在这里还有没有存在的理由）**
1. 二分类上，SFT 后的 VLM 只比冻结视觉嵌入加线性头高 0–0.02：9B 只看灾后图时显著，灾前加灾后时持平。
2. 5 级分级上有小幅优势，9B 勉强达到预注册门槛，4B 没有达到。中间等级对所有模型都不可判定。
3. 弃答和可靠性方面没有优势。
4. 因此，**不能**把"VLM 经 SFT 后作为灾后识别工具优于专用视觉模型"写成主要结论。能写的是：开源 VLM 用少量数据 SFT 后，可以从明显落后于闭源模型变为超过闭源零样本，并追平专用视觉基线，同时给出等级输出，且在分级上有边缘优势。文字解释的价值仍待人工评估。

## 10. 补充预注册：检索增强对照（2026-10-22，在任何检索运行之前写入）

**问题**：参照 Chen 等（arXiv 2610.02451）的"检索带标签记忆"思路。不做训练，只把检索到的带标签训练样本提供给模型，能否达到 SFT 的水平？如果能，VLM 在检索之外是否还有额外贡献？

**记忆库**：train 和 val 的灾后图共 1,949 栋。用冻结的 DINOv2-base 提取嵌入，按余弦相似度检索；测试火灾不进入记忆库。

**对照组**
- (a) 嵌入 kNN：P(被毁) 取 top-k 邻居标签按相似度加权的平均，k = 4、10、25、50。在全量 test 上评估，并在 400 栋子集上评估。
- (b) Qwen3.8-27B，400 栋子集，三种条件：
  - 零样本（已有结果）；
  - 检索示例：4 个最近邻，附图像、二分类结局和 DINS 等级；
  - 随机示例：从记忆库按种子固定抽 4 个，被毁和存活各 2 个，用来控制"有示例"本身的作用。
- (c) Claude Sonnet 5.5，400 栋子集，只跑"检索示例"一种条件。
- 提示词：先给 4 张示例图和各自的结局，最后一张是待判定的建筑；输出 JSON，包含 p_destroyed。

**判定**（400 栋子集，同一批建筑，95% 事件 bootstrap）

| 编号 | 比较 | 判定 |
|---|---|---|
| R1 | Qwen 检索示例 − Qwen 零样本 | 区间下界 > 0，记为"示例有帮助" |
| R2 | Qwen 检索示例 − Qwen 随机示例 | 区间下界 > 0，记为"检索相似样本才有帮助，不只是有示例" |
| R3 | Qwen 检索示例 − 嵌入 4 近邻投票 | 区间下界 > 0，记为"VLM 在照抄邻居标签之外有贡献" |
| R4 | 描述性比较 | 与 SFT 4B / 9B 和冻结线性头比较 |

### 第 10 节结果：检索增强（2026-10-22，按 R1–R4 判定）

全部结果见 `output/experiments/postfire/retrieval/report.md`。比较均在 400 栋子集上进行，同一批建筑，区间为 95% 事件 bootstrap。

| 编号 | 比较 | ΔAUROC [95% CI] | 判定 |
|---|---|---|---|
| R1 | Qwen 检索示例 − Qwen 零样本 | +0.019 [−0.023, +0.061] | 未达标 |
| R2 | Qwen 检索示例 − Qwen 随机示例 | +0.043 [−0.017, +0.096] | 未达标 |
| R3 | Qwen 检索示例 − 嵌入 4 近邻投票 | +0.024 [−0.031, +0.078] | 未达标 |
| R4 | Qwen 检索示例 − 4B SFT / − 冻结线性头 | −0.145 / −0.135 | 远低于两者 |
| R4 | Sonnet 检索示例 − Sonnet 零样本 | −0.012 [−0.069, +0.038] | 没有帮助 |

嵌入 kNN 的结果随 k 增大而提高：k=4 时 0.795，k=50 时 0.886；但在全量 test 上，k=50 仍不如线性头（0.824 对 0.881）。

**结论**：不训练、只靠"检索带标签的示例"（参照 Chen 等 2610.02451），在真实结局上无法替代训练；用 4 个检索示例做少样本提示，几个模型都没有显著改进。
